# Offline unit-test deps for the runtime agent's telemetry instrumentation.
#
# Deliberately NOT deploy/runtime-agent/requirements.txt: these tests must run in
# CI with no AWS credentials, no network at test time, and no Playwright/Node
# install. Only what's needed to build a real Strands Agent against a mocked
# model and read the spans back out of an in-memory exporter.
#
# Floor is 1.53.0, not 1.52.0: main.py passes cache_tools="default" (a string) and
# relies on the tools cachePoint inheriting ttl from cache_config.ttl. That
# inheritance (_build_tools_cache_point in strands/models/bedrock.py) only exists
# from 1.53.0; on 1.52.0 the tools cachePoint ships without ttl (defaults 5m),
# which breaks test_prompt_cache's ttl=="1h" assertion and yields a mixed-TTL
# request Bedrock extended-TTL validation can reject (TEAM-3961, F1).
#
# Ceiling is <1.55, matching deploy/runtime-agent/requirements.txt EXACTLY so the
# tests and the deployed image always resolve the same minor and can never assert
# different span shapes than prod emits. The ceiling exists because a minor SDK
# bump can MOVE span shape: 1.55.1 relocated the system prompt from a plain
# `system_prompt` span attribute (which it only ever occupied by **kwargs
# passthrough) to the semconv `gen_ai.system.message` event, and the unbounded
# `>=` this line used to carry picked that up overnight and reddened an unrelated
# PR. Same doctrine as mcp<2 / bedrock-agentcore<2: a version bump is a
# deliberate, test-verified edit here, not whatever pip resolves that minute.
#
# 1.55 is NOT a telemetry regression and this ceiling is not a quarantine:
# test_telemetry_spans.py asserts the prompt on whichever carrier the installed
# version is contracted to use, so lifting to 1.55.x is a one-line change when
# someone wants it (TEAM-4355;
# docs/evidence/TEAM-4355/system-prompt-span-contract.md).
strands-agents>=1.53.0,<1.55
boto3>=1.43.0
opentelemetry-sdk>=1.29.0
# StrandsTelemetry.setup_otlp_exporter() imports the OTLP/HTTP span exporter at
# call time, so the fallback branch of main.py's _init_telemetry() can't be
# exercised without it. Constructing the exporter opens no connection — nothing
# is ever flushed, since that test emits no spans.
opentelemetry-exporter-otlp-proto-http>=1.29.0
pytest>=8.0.0
pytest-asyncio>=0.23.0
# image_reader guard tests build real PNGs and re-open the tiles it emits.
pillow>=11.2.1
# deploy/coding-agent-runtime/test_setup_failure_response.py exec's the coding
# runtime's main.py (FastAPI app). Only the import is needed — no server runs.
fastapi>=0.115.0
